# Travel App (Projeto Viagem)

**[Open the app](https://projeto-viagem-ten.vercel.app)** · [🇧🇷 Leia em português](#-português)

A mobile-first travel itinerary application designed to help users manage their trip details, view weather forecasts, and navigate easily to their destinations.

## Features

- **Daily Itinerary**: View detailed activities for each day of your trip.
- **Weather Integration**: Real-time weather forecasts for each day, including temperature and rain probability.
- **Navigation Links**: Direct integration with Google Maps, Waze, and Uber for seamless travel.
- **Responsive Design**: Optimized for mobile devices with a layout that adapts to desktop screens.
- **Interactive UI**: Smooth animations and a premium look and feel.

## Tech Stack

- **React**: UI library for building the interface.
- **Vite**: Fast build tool and development server.
- **CSS**: Custom styling with a focus on responsiveness and aesthetics.

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/UxUchoa/Projeto_Viagem.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd Projeto_Viagem
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

## Usage

To start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the port shown in your terminal).

## Project Structure

- `src/components`: Reusable UI components (DayCard, WeatherWidget, etc.).
- `src/data`: Static data files (itinerary.js).
- `src/assets`: Images and icons.
- `src/App.jsx`: Main application component.
- `src/index.css`: Global styles and variables.
